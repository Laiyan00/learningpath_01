Pertanyaan yang Sering Diajukan (FAQ)

Apakah saya bisa upgrade paket di kemudian hari?

Tentu saja. Anda dapat meningkatkan paket dari Starter ke Pro atau Business kapan saja langsung dari dasbor tanpa downtime pada website Anda.

Bagaimana cara klaim domain gratis pada paket Pro & Business?

Setelah pembayaran terkonfirmasi untuk siklus tahunan, Anda dapat langsung mendaftarkan nama domain .com atau .id secara gratis selama 1 tahun pertama.

Apakah ada garansi uang kembali?

Kami memberikan garansi uang kembali 100% dalam 30 hari pertama jika Anda merasa performa server kami tidak sesuai dengan kebutuhan proyek Anda.
